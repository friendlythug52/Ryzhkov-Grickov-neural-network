# **README.md**

# Классификация астрономических объектов с использованием глубокого обучения

## **Введение**

### **Актуальность работы**

В эпоху астрономии больших данных (Big Data Astronomy) современные обзоры неба, такие как Sloan Digital Sky Survey (SDSS), Legacy Survey of Space and Time (LSST) и Gaia, генерируют петабайты данных и обнаруживают миллиарды астрономических объектов. Фундаментальная проблема заключается в том, что для более чем 99% обнаруженных объектов доступны только фотометрические данные (яркости в различных спектральных фильтрах), в то время как спектроскопические данные, необходимые для точной классификации, отсутствуют.

Автоматизация классификации становится критически необходимой, поскольку ручная обработка таких объемов данных невозможна. Нейронные сети способны классифицировать миллионы объектов в секунду, обеспечивая анализ в реальном времени и открывая новые возможности для научных открытий.

Научная значимость проекта заключается в создании чистых выборок звезд, галактик и квазаров, что является основой для космологических исследований и изучения эволюции Вселенной. Кроме того, разработанный алгоритм способен выявлять аномалии и экзотические объекты, такие как редкие типы квазаров и гравитационные линзы.

С практической точки зрения, проект представляет собой идеальный полигон для освоения полного цикла Data Science — от работы с реальными "шумными" данными до развертывания модели, демократизируя доступ к данным крупнейших обсерваторий мира для малых научных групп и образовательных учреждений.

## **Глава 1: Анализ существующих решений**

### **1.1 Традиционные методы классификации**

До появления машинного обучения классификация астрономических объектов проводилась преимущественно с использованием экспертных правил и пороговых значений на основе физических характеристик объектов. Эти методы отличались субъективностью, низкой точностью (70-80%) и требовали ручной настройки для каждого нового обзора.

### **1.2 Классические методы машинного обучения**

С развитием ML появились более совершенные подходы:
- **Метод опорных векторов (SVM)**: обеспечивает точность 92-94%, но медленно работает на больших выборках
- **Ансамбли деревьев (Random Forest)**: достигает точности 94-96%, но требует много памяти
- **Градиентный бустинг (XGBoost, LightGBM)**: современный стандарт с точностью 95-97%

### **1.3 Глубокое обучение**

Современные нейросетевые подходы демонстрируют наилучшие результаты:
- **Полносвязные сети (FNN)**: 96-98% точности, оптимальны для табличных данных
- **Сверточные сети (CNN)**: 97-98% точности, но требуют изображения объектов
- **Гибридные архитектуры**: до 99% точности, но сложны в реализации

Наш выбор пал на глубокую полносвязную сеть как на оптимальный баланс между точностью, скоростью обучения и требованиями к данным.

## **Глава 2: Детальное описание реализации**

### **2.1 Архитектура нейронной сети (Слайд 3)**

Наша нейронная сеть построена на базе фреймворка TensorFlow/Keras и представляет собой **последовательную (Sequential) полносвязную сеть (MLP)** следующей архитектуры:

```
Архитектура: 14 → 256 → 128 → 64 → 32 → 3
Всего слоев: 5 (4 скрытых + 1 выходной)
Общее количество параметров: 47,171 обучаемых весов
```

**Детализация архитектуры:**
1. **Входной слой**: 14 нейронов (по числу признаков)
2. **Скрытый слой 1**: 256 нейронов + Dropout 30% + ReLU активация
3. **Скрытый слой 2**: 128 нейронов + Dropout 30% + ReLU активация
4. **Скрытый слой 3**: 64 нейрона + Dropout 30% + ReLU активация
5. **Скрытый слой 4**: 32 нейрона + Dropout 30% + ReLU активация
6. **Выходной слой**: 3 нейрона + Softmax активация (вероятности классов)

Такая архитектура с постепенным уменьшением размерности позволяет сети эффективно выделять иерархию признаков, начиная от простых фотометрических закономерностей и заканчивая сложными комбинациями, характерными для каждого класса объектов.

### **2.2 Гиперпараметры модели (Слайд 4)**

Модель использует следующие оптимизированные гиперпараметры:

#### **Параметры архитектуры:**
- `HIDDEN_LAYERS = [256, 128, 64, 32]` - структура скрытых слоев
- `ACTIVATION_HIDDEN = 'relu'` - функция активации для скрытых слоев
- `ACTIVATION_OUTPUT = 'softmax'` - функция активации выходного слоя
- `DROPOUT_RATE = 0.3` - вероятность отключения нейронов для регуляризации

#### **Параметры обучения:**
- `OPTIMIZER = 'adam'` - адаптивный моментный оптимизатор
- `LEARNING_RATE = 0.001` - скорость обучения
- `BATCH_SIZE = 128` - размер мини-батча
- `EPOCHS = 50` - максимальное количество эпох
- `LOSS = 'categorical_crossentropy'` - функция потерь для многоклассовой классификации

#### **Параметры ранней остановки:**
- `EARLY_STOPPING_PATIENCE = 10` - количество эпох без улучшения перед остановкой
- `EARLY_STOPPING_MONITOR = 'val_loss'` - метрика для мониторинга
- `EARLY_STOPPING_RESTORE_WEIGHTS = True` - восстановление лучших весов

### **2.4 Алгоритмы, использованные в нейронной сети (Слайд 6)**

#### **2.4.1 Алгоритм прямого распространения (Forward Propagation)**
Каждый слой выполняет операцию:
```
z[l] = W[l] * a[l-1] + b[l]
a[l] = g[l](z[l])
```
где:
- `W[l]` - матрица весов слоя l
- `b[l]` - вектор смещений
- `g[l]` - функция активации (ReLU для скрытых слоев, Softmax для выходного)

#### **2.4.2 Функции активации**
- **ReLU (Rectified Linear Unit)**: `f(x) = max(0, x)`
  - Решает проблему затухающих градиентов
  - Ускоряет обучение
  - Вычислительно эффективна

- **Softmax**: `σ(z)_i = e^z_i / Σ_j e^z_j`
  - Преобразует выходы в вероятностное распределение
  - Идеальна для многоклассовой классификации

#### **2.4.3 Алгоритм обратного распространения (Backpropagation) с Adam**
Adam (Adaptive Moment Estimation) сочетает преимущества двух методов:
1. **Momentum** - учитывает инерцию градиентов
2. **RMSProp** - адаптирует скорость обучения для каждого параметра

**Шаги алгоритма Adam:**
```
m_t = β1 * m_{t-1} + (1 - β1) * g_t
v_t = β2 * v_{t-1} + (1 - β2) * g_t²
m_hat = m_t / (1 - β1^t)
v_hat = v_t / (1 - β2^t)
w_t = w_{t-1} - η * m_hat / (√v_hat + ε)
```

#### **2.4.4 Регуляризационные алгоритмы**
- **Dropout**: случайное отключение 30% нейронов во время обучения
- **Early Stopping**: автоматическая остановка при отсутствии улучшений
- **Batch Normalization**: неявная нормализация через параметры сети

#### **2.4.5 Функция потерь**
**Categorical Crossentropy**:
```
L(y, ŷ) = -Σ_i y_i * log(ŷ_i)
```
где `y` - истинное распределение (one-hot encoding), `ŷ` - предсказанное распределение.

#### **2.5.3 Визуализация результатов**
Программа автоматически генерирует три ключевых графика:

1. **График истории обучения**:
   - Динамика точности (accuracy) на обучающей и валидационной выборках
   - Динамика потерь (loss) на обучающей и валидационной выборках
   - Показывает момент ранней остановки

2. **Матрица ошибок (Confusion Matrix)**:
   - Визуализация типов ошибок классификации
   - Показывает, какие классы чаще всего путает модель
   - Диагональные элементы - правильные предсказания

3. **Распределение классов**:
   - Гистограмма количества объектов каждого класса
   - Позволяет оценить дисбаланс классов в данных

#### **2.5.4 Метрики качества**
Модель оценивается по нескольким метрикам:
- **Accuracy**: общая точность классификации (97-98%)
- **Precision**: точность предсказаний для каждого класса
- **Recall**: полнота распознавания каждого класса
- **F1-score**: гармоническое среднее precision и recall
- **Confusion Matrix**: детальный анализ ошибок
