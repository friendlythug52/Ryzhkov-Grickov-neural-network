# Ryzhkov-Grickov-neural-network
# **КЛАССИФИКАЦИЯ АСТРОНОМИЧЕСКИХ ОБЪЕКТОВ С ИСПОЛЬЗОВАНИЕМ ГЛУБОКОГО ОБУЧЕНИЯ**

## **Аннотация**

Данный проект представляет собой комплексное решение для автоматической классификации астрономических объектов (звезд, галактик и квазаров) по данным Слоановского цифрового обзора неба (SDSS). Реализована **глубокая нейронная сеть** с архитектурой 256-128-64-32 нейронов, достигающая точности **97-98%** на тестовой выборке. Проект включает полный ML-пайплайн: от загрузки и предобработки данных до обучения модели и визуализации результатов.

---

## **1. Введение и постановка задачи**

### **1.1. Актуальность проблемы**

Астрономические обзоры, такие как SDSS, генерируют **миллионы наблюдений** ежегодно. Ручная классификация объектов становится невозможной, что требует разработки **автоматических систем** классификации. Точная идентификация типа объекта необходима для:
- Поиска редких астрономических явлений
- Статистического анализа распределения объектов
- Планирования последующих наблюдений

### **1.2. Цели проекта**

1. Разработать **точную модель классификации** астрономических объектов
2. Создать **воспроизводимый пайплайн** обработки данных
3. Обеспечить **интерпретируемость** результатов
4. Создать основу для **дальнейших исследований**

### **1.3. Исходные данные**

Используется датасет **star_classification-3.csv**, содержащий ~100,000 объектов SDSS с 14 признаками:
- **Координаты**: alpha, delta
- **Фотометрические данные**: u, g, r, i, z
- **Технические параметры**: run_ID, cam_col, field_ID
- **Спектроскопические данные**: redshift, plate, MJD, fiber_ID

## **2. Методология**

### **2.1. Архитектурное решение**

Выбрана **глубокая полносвязная нейронная сеть** (Fully Connected Neural Network) по следующим причинам:

1. **Эффективность для табличных данных**
2. **Доказанная точность ~98%** в предыдущих исследованиях
3. **Баланс сложности и производительности**

### **2.2. Ключевые особенности подхода**

#### **2.2.1. Обработка данных**
- **Автоматическое обнаружение и замена** аномальных значений (-9999)
- **Стратифицированное разделение** для сохранения распределения классов
- **Стандартизация признаков** (StandardScaler)

#### **2.2.2. Предотвращение переобучения**
- **Dropout слои** (30%) после каждого скрытого слоя
- **Ранняя остановка** с восстановлением лучших весов
- **Валидационный набор** (16% данных)

#### **2.2.3. Оценка качества**
- **Многомерная оценка**: accuracy, precision, recall, F1-score
- **Матрица ошибок** для анализа типичных ошибок
- **Визуализация истории обучения**

## **3. Техническая реализация**


### **3.2. Детали архитектуры**

```python
# Архитектура нейронной сети
Архитектура: 14 → 256 → 128 → 64 → 32 → 3
Активации: ReLU (скрытые слои), Softmax (выходной)
Dropout: 30% после каждого скрытого слоя
Параметры: 47,171 обучаемых весов
```

### **3.3. Параметры обучения**

```python
Оптимизатор: Adam (learning_rate=0.001)
Функция потерь: categorical_crossentropy
Батч-размер: 128 объектов
Максимум эпох: 50
Ранняя остановка: patience=10 эпох
```

### **4.2. Анализ ошибок**

#### **4.2.1. Типичные ошибки классификации**
1. **Звезды ↔ Галактики** (наиболее частые ошибки)
2. **Квазары → Звезды** (редкие, но значимые ошибки)
3. **Галактики → Квазары** (наиболее редкие ошибки)

#### **4.2.2. Причины ошибок**
- **Схожие фотометрические профили** звезд и галактик
- **Редкость квазаров** в обучающей выборке
- **Шум в измерениях** для слабых объектов


### **Приложение B: Математические основы**

#### **Функция потерь (Categorical Crossentropy)**
```
L(y, ŷ) = -Σ y_i * log(ŷ_i)
где y - истинное распределение, ŷ - предсказанное
```

#### **Оптимизатор Adam**
```
m_t = β1*m_{t-1} + (1-β1)*g_t
v_t = β2*v_{t-1} + (1-β2)*g_t²
w_t = w_{t-1} - η * m_t / (√v_t + ε)
```
