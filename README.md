# **README.md - Классификация астрономических объектов с использованием глубокого обучения**

## **Введение**

### **Актуальность работы в контексте современной астрономии**

#### **Эра Big Data в астрономии**
Современные астрономические обзоры переживают революцию в области обработки данных. Проекты следующего поколения генерируют беспрецедентные объемы информации:

| Обзор неба | Объем данных в год | Количество объектов | Период работы |
|------------|-------------------|---------------------|---------------|
| **LSST (Vera C. Rubin)** | 15-20 Петабайт | 20+ миллиардов | 2024-2034 |
| **Gaia (ESA)** | 1 Петабайт | 1.8 миллиарда | 2013-2025 |
| **SDSS (Sloan)** | 60 Терабайт | 500 миллионов | 2000-2020 |
| **Pan-STARRS** | 40 Терабайт | 3 миллиарда | 2010-2014 |

Эта "информационная лавина" создает фундаментальный вызов: **как эффективно обрабатывать и классифицировать миллиарды объектов при ограниченных вычислительных ресурсах?**

#### **Критическая проблема: дефицит спектроскопических данных**
Для точной классификации астрономических объектов традиционно требуются спектроскопические наблюдения, которые:
- **Дороги** (стоимость ~$500 за объект для крупных телескопов)
- **Медленны** (секунды-минуты на объект vs миллисекунды для фотометрии)
- **Ограничены по пропускной способности** (одновременно можно наблюдать ~1000 объектов)

**Статистика SDSS**:
- Обнаружено: ~500 миллионов объектов
- Имеют спектры: ~4 миллиона (менее 1%)
- Только фотометрия: ~496 миллионов (более 99%)

Таким образом, **фотометрическая классификация становится не опцией, а необходимостью** для обработки подавляющего большинства наблюдаемых объектов.

#### **Научная значимость**
Точная классификация является фундаментом для:

1. **Космологические исследования**:
   - Измерение параметров космологической модели ΛCDM
   - Изучение крупномасштабной структуры Вселенной
   - Поиск и исследование темной материи и темной энергии

2. **Эволюция галактик**:
   - Определение функций светимости
   - Изучение звездообразования в разные эпохи
   - Анализ химического состава и металличности

3. **Поиск редких и экзотических объектов**:
   - Квазары высокого красного смещения (z > 6)
   - Гравитационные линзы
   - Сверхновые различных типов
   - Транзиенты и переменные объекты

4. **Многоканальная астрономия**:
   - Идентификация источников для гравитационно-волновой астрономии
   - Сопоставление с данными нейтринных обсерваторий
   - Подготовка целей для последующих спектроскопических наблюдений

#### **Технологический императив**
Автоматизация классификации критически необходима по следующим причинам:

1. **Скорость обработки**:
   - Человек-эксперт: ~1 объект в минуту

### **1.3 Подходы глубокого обучения**

#### **1.3.1 Полносвязные нейронные сети (FNN)**
```python
import tensorflow as tf
from tensorflow import keras
from tensorflow.keras import layers

def build_fnn_architecture(input_dim):
    """Базовая архитектура FNN для астрономической классификации"""
    model = keras.Sequential([
        layers.Input(shape=(input_dim,)),
        layers.Dense(128, activation='relu'),
        layers.Dropout(0.3),
        layers.Dense(64, activation='relu'),
        layers.Dropout(0.3),
        layers.Dense(32, activation='relu'),
        layers.Dense(3, activation='softmax')
    ])
    
    model.compile(
        optimizer='adam',
        loss='categorical_crossentropy',
        metrics=['accuracy']
    )
    return model

# Преимущества:
# - Автоматическое извлечение признаков
# - Моделирование сложных нелинейных зависимостей
# - Хорошая масштабируемость

# Производительность в исследованиях:

# - Fiorentin et al. (2018): 97.2% на SDSS
```

#### **1.3.2 Сверточные нейронные сети (CNN) для изображений**
```python
def build_cnn_astronomy(input_shape=(64, 64, 3)):
    """CNN для классификации по изображениям объектов"""
    model = keras.Sequential([
        # Первый сверточный блок
        layers.Conv2D(32, (3, 3), activation='relu', input_shape=input_shape),
        layers.BatchNormalization(),
        layers.MaxPooling2D((2, 2)),
        
        # Второй сверточный блок
        layers.Conv2D(64, (3, 3), activation='relu'),
        layers.BatchNormalization(),
        layers.MaxPooling2D((2, 2)),
        
        # Третий сверточный блок
        layers.Conv2D(128, (3, 3), activation='relu'),
        layers.BatchNormalization(),
        layers.MaxPooling2D((2, 2)),
        
        # Полносвязная часть
        layers.Flatten(),
        layers.Dense(256, activation='relu'),
        layers.Dropout(0.5),
        layers.Dense(128, activation='relu'),
        layers.Dense(3, activation='softmax')
    ])
    return model

# Особенности:
# - Использует непосредственно изображения cutouts
# - Извлекает пространственные особенности
# - Требует значительно больше данных для обучения

# - Время обучения: 10-20 часов на GPU
```

#### **1.3.3 Гибридные и специализированные архитектуры**

**Многозадачное обучение (Multi-task Learning)**:
```python
def multi_task_astronomy(input_dim):
    """Модель для совместной классификации и регрессии"""
    
    input_layer = layers.Input(shape=(input_dim,))
    
    # Общие скрытые слои
    x = layers.Dense(256, activation='relu')(input_layer)
    x = layers.Dropout(0.3)(x)
    x = layers.Dense(128, activation='relu')(x)
    
    # Выход для классификации
    classification_output = layers.Dense(3, activation='softmax', name='classification')(x)
    
    # Выход для регрессии (красное смещение)
    regression_output = layers.Dense(1, activation='linear', name='redshift')(x)
    
    model = keras.Model(
        inputs=input_layer,
        outputs=[classification_output, regression_output]
    )
    
    # Компиляция с разными функциями потерь
    model.compile(
        optimizer='adam',
        loss={
            'classification': 'categorical_crossentropy',
            'redshift': 'mse'
        },
        loss_weights={'classification': 0.7, 'redshift': 0.3},
        metrics={'classification': ['accuracy']}
    )
    return model

# Преимущества:
# - Совместное обучение связанным задачам
# - Улучшение обобщающей способности
# - Получение дополнительной информации об объектах
```

**Внимание и трансформеры**:
```python
from tensorflow.keras.layers import MultiHeadAttention, LayerNormalization

def transformer_astronomy(input_dim, num_heads=4):
    """Архитектура с механизмом внимания"""
    
    inputs = layers.Input(shape=(input_dim,))
    
    # Позиционное кодирование (для последовательности признаков)
    position_encoding = layers.Embedding(
        input_dim=input_dim,
        output_dim=64
    )(tf.range(input_dim))
    
    # Объединение с признаками
    x = layers.Dense(64)(inputs)
    x = x + position_encoding
    
    # Блок внимания
    attention_output = MultiHeadAttention(
        num_heads=num_heads,
        key_dim=64
    )(x, x)
    
    # Нормализация и полносвязные слои
    x = LayerNormalization()(x + attention_output)
    x = layers.Dense(128, activation='relu')(x)
    x = layers.Dense(64, activation='relu')(x)
    outputs = layers.Dense(3, activation='softmax')(x)
    
    model = keras.Model(inputs=inputs, outputs=outputs)
    return model
```

#### **1.4.1 Критерии выбора для нашей задачи**

**Требования проекта**:
1. **Точность** ≥ 97% (научное требование)
2. **Скорость обучения** < 1 часа (ограничения вычислений)
3. **Только фотометрические данные** (без изображений)
4. **Воспроизводимость** (фиксированные random seeds)
5. **Масштабируемость** до миллионов объектов

**Анализ компромиссов**:

1. **Точность vs Скорость**:
   - Гибридные модели: максимальная точность (98.2%), но медленные (3+ часа)
   - Наша FNN: почти максимальная точность (97.8%), быстрая (25 минут)
   - XGBoost: хорошая точность (95.3%), очень быстрая (8 минут)

2. **Интерпретируемость vs Производительность**:
   - Random Forest: высокая интерпретируемость, но склонность к переобучению
   - Нейросети: "черный ящик", но лучшая обобщающая способность

3. **Требования к данным**:
   - CNN: требуют изображения (недоступны для всех объектов)
   - FNN: работают с табличными данными (всегда доступны)

**Вывод**: Полносвязная нейронная сеть представляет собой оптимальный компромисс для нашей задачи, обеспечивая близкую к максимальной точность при разумных вычислительных затратах и работе с доступными данными.

#### **1.5.2 Принцип постепенного сжатия информации**
Архитектура следует принципу "воронки":
1. **256 нейронов**: извлечение большого количества низкоуровневых признаков
2. **128 нейронов**: комбинация признаков в более сложные паттерны
3. **64 нейрона**: выделение наиболее информативных комбинаций
4. **32 нейрона**: формирование "отпечатка" объекта для классификации

Эта структура аналогична процессу научного анализа:
- Наблюдение множества измерений → Выявление корреляций → Формулировка гипотез → Классификация

#### **1.5.3 Регуляризационная стратегия**
Каждый скрытый слой сопровождается Dropout 30%, что обеспечивает:
1. **Предотвращение ко-адаптации** нейронов
2. **Эффективное ансамблирование** внутри одной сети
3. **Улучшение обобщающей способности**

Ранняя остановка с восстановлением лучших весов дополнительно защищает от переобучения.

### **1.6 Ожидаемые преимущества и ограничения**

#### **Ожидаемые преимущества**:

3. **Масштабируемость** до миллиардов объектов
4. **Адаптивность** к новым типам данных

#### **2.1.3 Функции активации и их роль**

**ReLU (Rectified Linear Unit)**:
```python
def relu(x):
    return max(0, x)

# Производная:
def relu_derivative(x):
    return 1 if x > 0 else 0
```

**Преимущества ReLU для нашей задачи**:
1. **Вычислительная эффективность**: простые операции max(0, x)
2. **Решение проблемы затухающих градиентов**: производная = 1 для x > 0
3. **Разреженные активации**: только ~50% нейронов активны → эффективное представление
4. **Ускоренная сходимость**: в 6 раз быстрее, чем sigmoid/tanh

**Softmax для выходного слоя**:
```python
def softmax(z):
    exp_z = np.exp(z - np.max(z))  # Стабильная версия
    return exp_z / np.sum(exp_z)
```

**Интерпретация выхода Softmax**:
```
Выход модели: [0.85, 0.12, 0.03]
Интерпретация: 
- 85% вероятность: STAR
- 12% вероятность: GALAXY  
- 3% вероятность: QSO
```

#### **2.1.4 Механизмы регуляризации**

**Dropout (30%)**:
```python
class Dropout(tf.keras.layers.Layer):
    def call(self, inputs, training=False):
        if training:
            # Случайная маска: 70% нейронов остаются
            mask = tf.random.uniform(tf.shape(inputs)) > 0.3
            return inputs * tf.cast(mask, tf.float32) / 0.7  # Scale correction
        return inputs
```

**Эффекты Dropout**:
1. **Предотвращение ко-адаптации**: нейроны учатся быть полезными независимо
2. **Ансамблирование**: каждая forward pass использует разные подсети
3. **Улучшение обобщения**: снижает переобучение на 15-20%

**Early Stopping с восстановлением весов**:
```python
early_stopping = EarlyStopping(
```

#### **2.2.3 Оптимизатор Adam: детальная конфигурация**

```python
optimizer = Adam(
    learning_rate=0.001,
    beta_1=0.9,      # Коэффициент для первого момента

    epsilon=1e-07,   # Численная стабильность
    amsgrad=False    # Не использовать AMSGrad вариант
)
```

**Как работает Adam**:
1. **Адаптивная скорость обучения** для каждого параметра
2. **Учет истории градиентов** (моменты первого и второго порядка)
3. **Коррекция смещения** для начальных итераций

**Обновление весов в Adam**:
```
m_t = β1 * m_{t-1} + (1 - β1) * g_t      # Первый момент (среднее)
v_t = β2 * v_{t-1} + (1 - β2) * g_t²     # Второй момент (дисперсия)

m_hat = m_t / (1 - β1^t)                # Коррекция смещения
v_hat = v_t / (1 - β2^t)

w_t = w_{t-1} - η * m_hat / (√v_hat + ε)  # Обновление веса
```

#### **2.2.4 Функция потерь: Categorical Crossentropy**

**Математическая формулировка**:
```
L(y, ŷ) = -Σ_i y_i * log(ŷ_i)
где:
- y_i ∈ {0, 1} (one-hot encoding истинного класса)
- ŷ_i ∈ [0, 1] (предсказанная вероятность)
- Σ_i ŷ_i = 1 (условие нормировки softmax)
```

**Стабильная реализация**:
```python
def stable_categorical_crossentropy(y_true, y_pred):
    # Предотвращение log(0) = -inf
    y_pred = tf.clip_by_value(y_pred, 1e-7, 1 - 1e-7)
    
    # Вычисление потерь
    loss = -tf.reduce_sum(y_true * tf.math.log(y_pred), axis=-1)
    return tf.reduce_mean(loss)
```

**Интерпретация потерь**:
- Loss = 0.0: идеальные предсказания
- Loss = 0.693: случайные предсказания (log(1/3) ≈ 0.693)
- Loss > 1.0: хуже случайных предсказаний

**Значение -9999.0 в астрономических данных**:

- **Частота**: ~1-5% значений в различных признаках
- **Обработка**: замена на среднее значение признака

```python
# Алгоритм обработки аномалий
def handle_anomalies(df, anomaly_value=-9999.0):
    """Замена аномальных значений на средние"""
    
    processed_df = df.copy()
    
    for column in numeric_columns:
        # Подсчет аномалий
        anomaly_mask = processed_df[column] == anomaly_value
        anomaly_count = anomaly_mask.sum()
        
        if anomaly_count > 0:
            # Вычисление среднего без аномалий
            valid_values = processed_df[~anomaly_mask][column]
            mean_value = valid_values.mean()
            
            # Замена
            processed_df.loc[anomaly_mask, column] = mean_value
            
            # Логирование
            print(f"Заменено {anomaly_count} значений в {column}")
    
    return processed_df
```

### **2.4 Алгоритмы, использованные в нейронной сети (Слайд 6)**

#### **2.4.1 Прямое распространение (Forward Propagation)**

**Математическая модель одного слоя**:
```python
def dense_layer_forward(A_prev, W, b, activation):
    """
    A_prev: активации предыдущего слоя (m, n_prev)
    W: веса (n_prev, n_current)
    b: смещения (1, n_current)
    activation: функция активации
    """
    
    # Линейная часть
    Z = np.dot(A_prev, W) + b
    
    # Нелинейность
    if activation == "relu":
        A = np.maximum(0, Z)
    elif activation == "softmax":
        # Стабильная версия softmax
        exp_Z = np.exp(Z - np.max(Z, axis=1, keepdims=True))
        A = exp_Z / np.sum(exp_Z, axis=1, keepdims=True)
    
    cache = (A_prev, W, b, Z)  # Сохраняем для обратного распространения
    return A, cache
```

**Полный forward pass через сеть**:
```python
def model_forward(X, parameters, activations):
    """
    X: входные данные (m, 14)
    parameters: словарь весов и смещений
    activations: список функций активации для каждого слоя
    """
    
    caches = []
    A = X
    
    # Проход через скрытые слои
    for l in range(1, L):  # L = количество слоев
        A_prev = A
        W = parameters[f"W{l}"]
        b = parameters[f"b{l}"]
        activation = activations[l-1]  # Для скрытых слоев: ReLU
        
        A, cache = dense_layer_forward(A_prev, W, b, activation)
        caches.append(cache)
        
        # Применяем Dropout во время обучения
        if training:
            D = np.random.rand(*A.shape) > dropout_rate
            A = A * D
            A = A / (1 - dropout_rate)  # Инверсный dropout
            dropout_cache = D
            caches[-1] += (dropout_cache,)
    
    # Выходной слой
    W_out = parameters[f"W{L}"]
    b_out = parameters[f"b{L}"]
    AL, cache = dense_layer_forward(A, W_out, b_out, "softmax")
    caches.append(cache)
    
    return AL, caches
```

#### **2.4.2 Функция потерь и ее вычисление**

**Categorical Crossentropy с регуляризацией L2**:
```python
def compute_cost(AL, Y, parameters, lambd=0.01):
    """
    AL: предсказанные вероятности (m, 3)
    Y: истинные метки one-hot (m, 3)
    parameters: веса модели
    lambd: коэффициент L2 регуляризации
    """
    
    m = Y.shape[0]
    
    # Crossentropy loss
    cross_entropy = -np.sum(Y * np.log(AL + 1e-8)) / m
    
    # L2 регуляризация
    L2_regularization = 0
    for key in parameters:
        if key.startswith("W"):
            L2_regularization += np.sum(np.square(parameters[key]))
    
    L2_regularization = (lambd / (2 * m)) * L2_regularization
    
    # Общая функция потерь
    cost = cross_entropy + L2_regularization
    
    return cost
```

**Градиенты функции потерь**:
```python
def softmax_crossentropy_backward(AL, Y):
    """
    Градиент для softmax + crossentropy
    Упрощенная формула: dZ = AL - Y
    """
    dZ = AL - Y
    return dZ

def relu_backward(dA, Z):
    """
    Градиент ReLU: 1 если Z > 0, иначе 0
    """
    dZ = np.array(dA, copy=True)
    dZ[Z <= 0] = 0
    return dZ
```

#### **2.4.3 Обратное распространение (Backpropagation)**

**Алгоритм для одного слоя**:
```python
def dense_layer_backward(dA, cache, activation, lambd=0.01):
    """
    dA: градиент потерь по активациям текущего слоя
    cache: (A_prev, W, b, Z, [D]) сохраненные значения forward pass
    activation: функция активации
    lambd: коэффициент L2 регуляризации
    """
    
    if len(cache) == 5:  # Есть Dropout
        A_prev, W, b, Z, D = cache
        # Учитываем маску Dropout
        dA = dA * D
        dA = dA / (1 - dropout_rate)
    else:
        A_prev, W, b, Z = cache
    
    m = A_prev.shape[0]
    
    # Градиент по Z в зависимости от активации
    if activation == "relu":
        dZ = relu_backward(dA, Z)
    elif activation == "softmax":
        # Для выходного слоя градиент уже вычислен
        dZ = dA
    
    # Градиенты параметров
    dW = np.dot(A_prev.T, dZ) / m + (lambd / m) * W  # С L2 регуляризацией
    db = np.sum(dZ, axis=0, keepdims=True) / m
    
    # Градиент для предыдущего слоя
    dA_prev = np.dot(dZ, W.T)
    
    return dA_prev, dW, db
```

**Полный backward pass**:
```python
def model_backward(AL, Y, caches, activations, lambd=0.01):
    """
    AL: выходные активации
    Y: истинные метки
    caches: список кэшей от forward pass
    activations: список функций активации
    lambd: коэффициент L2 регуляризации
    """
    
    grads = {}
    L = len(caches)  # Количество слоев
    m = AL.shape[0]
    Y = Y.reshape(AL.shape)  # Ensure same shape
    
    # Инициализация backward pass
    # Для выходного слоя (softmax + crossentropy)
    current_cache = caches[L-1]
    dZ = AL - Y  # Специальный случай для softmax
    
    A_prev, W, b, Z = current_cache
    grads[f"dW{L}"] = np.dot(A_prev.T, dZ) / m + (lambd / m) * W
    grads[f"db{L}"] = np.sum(dZ, axis=0, keepdims=True) / m
    
    # Градиент для предыдущего слоя
    dA_prev = np.dot(dZ, W.T)
    
    # Обратный проход через скрытые слои
    for l in reversed(range(L-1)):
        current_cache = caches[l]
        activation = activations[l]  # ReLU для скрытых слоев
        
        dA_prev, dW, db = dense_layer_backward(
            dA_prev, current_cache, activation, lambd
        )
        
        grads[f"dW{l+1}"] = dW
        grads[f"db{l+1}"] = db
    
    return grads
```

#### **2.4.4 Оптимизатор Adam: полная реализация**

```python
def initialize_adam(parameters):
    """
    Инициализация моментов для Adam
    """
    L = len(parameters) // 2  # количество слоев
    v = {}
    s = {}
    
    for l in range(1, L + 1):
        v[f"dW{l}"] = np.zeros_like(parameters[f"W{l}"])
        v[f"db{l}"] = np.zeros_like(parameters[f"b{l}"])
        s[f"dW{l}"] = np.zeros_like(parameters[f"W{l}"])
        s[f"db{l}"] = np.zeros_like(parameters[f"b{l}"])
    
    return v, s

def update_parameters_with_adam(parameters, grads, v, s, t, 
                                learning_rate=0.001, 
                                beta1=0.9, beta2=0.999, epsilon=1e-8):
    """
    Обновление параметров с помощью Adam
    """
    L = len(parameters) // 2
    v_corrected = {}
    s_corrected = {}
    
    for l in range(1, L + 1):
        # Обновление моментов
        v[f"dW{l}"] = beta1 * v[f"dW{l}"] + (1 - beta1) * grads[f"dW{l}"]
        v[f"db{l}"] = beta1 * v[f"db{l}"] + (1 - beta1) * grads[f"db{l}"]
        
        s[f"dW{l}"] = beta2 * s[f"dW{l}"] + (1 - beta2) * np.square(grads[f"dW{l}"])
        s[f"db{l}"] = beta2 * s[f"db{l}"] + (1 - beta2) * np.square(grads[f"db{l}"])
        
        # Коррекция смещения
        v_corrected[f"dW{l}"] = v[f"dW{l}"] / (1 - np.power(beta1, t))
        v_corrected[f"db{l}"] = v[f"db{l}"] / (1 - np.power(beta1, t))
        
        s_corrected[f"dW{l}"] = s[f"dW{l}"] / (1 - np.power(beta2, t))
        s_corrected[f"db{l}"] = s[f"db{l}"] / (1 - np.power(beta2, t))
        
        # Обновление параметров
        parameters[f"W{l}"] -= learning_rate * v_corrected[f"dW{l}"] / (
            np.sqrt(s_corrected[f"dW{l}"]) + epsilon
        )
        parameters[f"b{l}"] -= learning_rate * v_corrected[f"db{l}"] / (
            np.sqrt(s_corrected[f"db{l}"]) + epsilon
        )
    
    return parameters, v, s
```

#### **2.4.5 Dropout: механизм и обоснование**

**Математическая формулировка Dropout**:
```python
def dropout_forward(A, dropout_rate, training=True):
    """
    Прямой проход с Dropout
    """
    if training:
        # Создаем маску
        D = np.random.rand(*A.shape) < (1 - dropout_rate)
        
        # Применяем маску
        A = A * D
        
        # Масштабируем для сохранения математического ожидания
        A = A / (1 - dropout_rate)
        
        cache = D
    else:
        # Во время тестирования: без Dropout
        cache = None
    
    return A, cache

def dropout_backward(dA, cache, dropout_rate):
    """
    Обратный проход через Dropout
    """
    D = cache
    
    # Применяем ту же маску
    dA = dA * D
    
    # Масштабируем
    dA = dA / (1 - dropout_rate)
    
    return dA
```

**Теоретическое обоснование Dropout**:
1. **Ансамблирование**: каждый forward pass использует другую подсеть
2. **Предотвращение ко-адаптации**: нейроны учатся быть полезными независимо
3. **Сети меньшего размера**: эффективное использование параметров

#### **2.4.6 Batch Normalization: альтернативный подход**

Хотя в нашей реализации мы не используем BatchNorm, рассмотрим его для полноты:

```python
def batch_norm_forward(Z, gamma, beta, epsilon=1e-5):
    """
    Прямой проход BatchNorm
    """
    mu = np.mean(Z, axis=0)
    var = np.var(Z, axis=0)
    
    Z_norm = (Z - mu) / np.sqrt(var + epsilon)
    Z_tilde = gamma * Z_norm + beta
    
    cache = (Z, Z_norm, mu, var, gamma, beta, epsilon)
    
    return Z_tilde, cache

def batch_norm_backward(dZ_tilde, cache):
    """
    Обратный проход через BatchNorm
    """
    Z, Z_norm, mu, var, gamma, beta, epsilon = cache
    m = Z.shape[0]
    
    dgamma = np.sum(dZ_tilde * Z_norm, axis=0)
    dbeta = np.sum(dZ_tilde, axis=0)
    
    dZ_norm = dZ_tilde * gamma
    dvar = np.sum(dZ_norm * (Z - mu) * (-0.5) * (var + epsilon)**(-1.5), axis=0)
    dmu = np.sum(dZ_norm * (-1) / np.sqrt(var + epsilon), axis=0) + dvar * np.mean(-2 * (Z - mu), axis=0)
    
    dZ = dZ_norm / np.sqrt(var + epsilon) + dvar * 2 * (Z - mu) / m + dmu / m
    
    return dZ, dgamma, dbeta
```

**Почему мы выбрали Dropout вместо BatchNorm**:
1. **Табличные данные**: BatchNorm более эффективен для изображений
2. **Простота**: Dropout проще в реализации и отладке
3. **Результаты**: сравнимые результаты при меньшей вычислительной сложности

```python
    print("\n✓ Все результаты сохранены в текущую директорию!")
    print("=" * 75)
    
    return nn, preprocessor, history, test_metrics
```
